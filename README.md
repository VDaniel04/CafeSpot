CafeSpot ☕

Platformă web pentru descoperirea, evaluarea și salvarea cafenelelor preferate.

📌 Obiectiv

CafeSpot ajută utilizatorii să găsească cafenelele potrivite prin recenzii, ratinguri și vizualizare pe hartă, facilitând totodată interacțiunea dintre clienți și proprietarii de cafenele.

🛠️ Tehnologii

Backend: Django (Python)

Frontend: HTML5, CSS3, JavaScript

Bază de date: SQLite

Management: Git/GitHub

🚀 Instalare

Bash
git clone https://github.com/VDaniel04/CafeSpot.git  
cd CafeSpot  
python -m venv venv  
pip install -r requirements.txt  
python manage.py migrate  
python manage.py runserver
